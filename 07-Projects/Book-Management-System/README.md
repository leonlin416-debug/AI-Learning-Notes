# Book Management System

## 1. 项目简介

本项目是一个基于 Python 开发的命令行图书管理系统，主要实现图书借阅、图书归还和借阅记录查询等基本功能。

系统区分会员用户和普通用户，不同身份的用户具有相应的操作权限，模拟了简单的图书借阅管理流程。

## 2. 主要功能

### 2.1 用户身份管理

系统包含两种用户类型：

- **会员用户（Member）**：拥有会员身份，可按照系统设定的会员规则使用借阅功能。
- **普通用户（Regular User）**：未开通会员身份，根据普通用户规则使用系统功能。

### 2.2 图书借阅（Borrow Books）

用户可以根据系统提示选择需要借阅的图书。

系统根据用户身份和图书状态进行相应判断，并处理借阅操作。

### 2.3 图书归还（Return Books）

用户可以归还已经借阅的图书，系统根据借阅信息更新图书状态。

### 2.4 查看借阅记录（View Borrowing Records）

用户可以查看相关借阅信息，了解图书借阅情况。

### 2.5 退出系统（Exit）

用户可以选择退出系统，结束当前操作。
